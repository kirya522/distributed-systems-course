## Документация по разработке сайта

Submodule init is required
```
git submodule update --init
```

To start server
```sh
hugo server --buildDrafts
```
server will start at http://localhost:1313/

Add new post
```sh
hugo new posts/<name>.md
```

To package artifact
```sh
hugo
```
